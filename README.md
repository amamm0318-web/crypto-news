# كريبتو حصري ₿

تطبيق ويب خفيف (ملف `index.html` واحد) لأخبار الكريبتو، واجهة عربية من اليمين لليسار.

## شنو فيه
- **📰 الأخبار**: مقالات تحليل أصلية بقلم صاحب الموقع، مع بحث وفلترة بالأقسام وحفظ المقالات المفضلة.
- **📊 الأسواق**: لائحة العملات بالصور والأسعار ونسبة التغير والقيمة السوقية (من CoinGecko).
- **⚡ مباشر**: عناوين من CoinDesk وCointelegraph وDecrypt مع رابط للمقال الأصلي، وزر ترجمة آلية لكل عنوان.
- شريط أسعار فوق (BTC وETH وSOL…) ووضع فاتح/داكن.

## كيفاش كيخدم
- الأسعار كتجي مباشرة من CoinGecko وكتتحفظ دقيقة فمتصفح الزائر لتقليل الطلبات.
- العناوين كيجيبها `scripts/fetch_news.py` كل ساعة عبر GitHub Actions (`.github/workflows/news.yml`) وكيكتبها فـ `news.json`.
- الترجمة الآلية من MyMemory وكتتحفظ أسبوع فالمتصفح.

## تحديث المحتوى
- مقال جديد: زيد عنصر فمصفوفة `NEWS` فـ `index.html`.
- تشغيل جلب العناوين يدويا: تبويب **Actions** ثم **Update news** ثم **Run workflow**.

## تنبيه
المحتوى للإعلام فقط وماشي نصيحة مالية. العناوين حقوقها لأصحابها، والموقع كيحيل للمقال الأصلي.
